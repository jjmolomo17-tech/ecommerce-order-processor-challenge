# E-Commerce Order Processor

## Project Description

The E-Commerce Order Processor is a single-page JavaScript application that allows users to manage, analyse and process order data.

The application demonstrates the practical use of JavaScript built-in objects and methods including String, Number, Math, Date, Array Methods, Set, Map, JSON and RegExp.

Users can:

- View orders
- Search orders
- Filter orders
- Analyse statistics
- View unique categories
- Lookup products
- Export JSON
- Import JSON
- Validate data

## Reflection Questions

### 1. Which built-in JavaScript object did you find most useful?

The Array object was the most useful because it made it easier to search, filter and calculate information from the order dataset using methods such as find(), filter(), map() and reduce().

### 2. Which challenge was the most difficult?

The JSON challenge was the most difficult because it required data conversion, error handling and refreshing multiple sections of the application after importing data.

### 3. What did you learn about choosing the right JavaScript method for a problem?

I learned that using built-in methods makes code cleaner, easier to read and easier to maintain. Choosing the correct method often reduces the amount of code required.

### 4. If you had more time, what would you improve?

I would add local storage, advanced filtering, sorting controls, charts and a responsive admin dashboard design.
